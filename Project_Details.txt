1. Linux or Windows VM Quickstart
-----------------------------------------------------------------------------------------------------------------------
Provision a resource group, virtual network, subnet, network security group, and a single Linux or Windows VM.
Configure boot diagnostics using a storage account.
Optionally, generate an SSH key pair or set up a Windows admin password automatically.
Include the external valumn , drive in linux and windows VM. Where we need to install NGINX and IIS web server and move 
the logs.

3. Web App with Secure Database Connectivity
-----------------------------------------------------------------------------------------------------------------------
Deploy an Azure App Service with an Azure SQL or MySQL database, and implement networking using a Virtual Network 
and Private Endpoint for the database.
Add Network Security Groups (NSGs) to restrict database access solely to the App Service subnet[2].
